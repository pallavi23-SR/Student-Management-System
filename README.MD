# Student Management System with Automated CI/CD Pipeline

## Project Description
This project is a simple Student Management System developed using HTML, CSS, and JavaScript. It demonstrates the implementation of an Automated CI/CD Pipeline using Git, GitHub, GitHub Actions, and GitHub Pages.

## Features
- Add Student
- Edit Student
- Delete Student
- View Student Records
- Responsive User Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Actions
- GitHub Pages

## CI/CD Workflow
1. Develop the application.
2. Commit changes using Git.
3. Push code to GitHub.
4. GitHub Actions runs automatically.
5. Website is deployed to GitHub Pages.
